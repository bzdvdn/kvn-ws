# v1 legacy

v1 is removed from the current tree and is not built in 2.0.0. It remains available only as an old release:

- [v1.4.1](https://github.com/bzdvdn/kvn-ws/releases/tag/v1.4.1)
- old `client.yaml`/`server.yaml` examples and instructions live in the `v1.4.1` tag

Use the old binary for v1. Current `kvn-web`, `kvn-client`, and `kvn-server` are v2-only. Do not mix v1 and v2 configs.

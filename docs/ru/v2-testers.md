# KVN 2.0 — инструкция тестера

Это release candidate для закрытой группы. v1 и v2 несовместимы; используйте только APK/бинарники 2.0.x.

## Что нужно

- Android 8.0+ (minSdk 26).
- APK из release candidate.
- Адрес сервера и token от администратора.
- Для production-домена с Let's Encrypt сертификат проверяется; `Allow insecure TLS` включайте только для self-signed lab-сервера.

## Подключение Android

1. Установите APK.
2. Откройте Settings → Allow insecure TLS (только для тестового сервера).
3. Добавьте сервер: вручную `https://HOST:443` + token или отсканируйте QR из kvn-web.
4. Connect.
5. Проверьте YouTube/сайт, `ping`, переключение Wi-Fi ↔ LTE, reconnect.
6. Настройте included/excluded apps и Direct domains (`.ru`) при необходимости.
7. Откройте сайт сервера в браузере: `https://HOST/` — должен открыться стриминговый сайт, `/login.html` — форма входа, случайный путь — 404.

## Что проверить

- [ ] YouTube и обычные сайты открываются.
- [ ] `ping 1.1.1.1` работает; `traceroute` может не работать.
- [ ] `.ru` идёт напрямую, остальное — через туннель.
- [ ] Disconnect/reconnect не оставляет зависший VPN.
- [ ] После перезагрузки телефона подключение восстанавливается.
- [ ] QR из kvn-web импортируется в Android.
- [ ] Несколько серверов переключаются без переустановки.
- [ ] `https://HOST/` отдаёт сайт, `/login.html` — форму, случайный путь — 404.
- [ ] `curl --http1.1 https://HOST/` работает (не только h2).

## Если не работает

Пришлите:

- модель телефона и версию Android;
- сервер (имя, не token);
- Settings → Diagnostics → Log level `debug`;
- логи из kvn-web (если есть) или Android logcat;
- время ошибки и что делали.

Не публикуйте token, QR и полные логи в открытых чатах.

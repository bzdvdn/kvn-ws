# v1 legacy

v1 удалён из текущего дерева и не собирается в 2.0.0. Он остаётся доступен только как старый релиз:

- [v1.4.1](https://github.com/bzdvdn/kvn-ws/releases/tag/v1.4.1)
- старые `client.yaml`/`server.yaml` и инструкции — в исходниках тега `v1.4.1`

Для v1 нужен старый бинарник; текущие `kvn-web`, `kvn-client` и `kvn-server` — только v2. Не используйте v1-конфиг с v2 и наоборот.
